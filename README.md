# Wildberries Multiprocessing Parser (Phones Category)

Парсер товаров категории «Телефоны» с маркетплейса Wildberries. Скрипт предназначен для обхода лимита выдачи (100 страниц / 5000 товаров) путем автоматического дробления ценовых диапазонов и использования многопоточности.

## Ключевые особенности

* **Рекурсивный обход лимитов**: Скрипт анализирует количество товаров в диапазоне. Если их больше 5000, он делит диапазон пополам, пока не добьется полной выгрузки данных.
* **Multiprocessing**: Использование модуля `Pool` позволяет скачивать данные в несколько потоков, что значительно ускоряет сбор.
* **Безопасность**: Заголовки (headers) и куки (cookies) вынесены в защищенные переменные окружения (`.env`).
* **Форматированный отчет**: Данные сохраняются в Excel с автоматической подстройкой ширины колонок для удобства чтения.

* **Python-dotenv**: Управление секретами.

## 📂 Структура проекта

* `main.py` — основной файл парсера.
* `TelephoneParser/` — папка для промежуточного хранения JSON-ответов (демо-данные).
* `range.txt` — лог рассчитанных ценовых диапазонов.
* `Телефоны.xlsx` — итоговый отчет.
* `.env.example` — шаблон для ваших Cookies и Headers.
