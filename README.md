# Wildberries Multiprocessing Parser (Phones Category)

Парсер товаров категории «Телефоны» с маркетплейса Wildberries. Скрипт предназначен для полного сбора данных в обход лимита выдачи (100 страниц / 5000 товаров) путем автоматического дробления ценовых диапазонов. Для ускорения сбора и сохранения JSON-файлов используется многопоточность.

## Ключевые особенности

* **Рекурсивный обход лимитов**: Скрипт анализирует количество товаров в диапазоне. Если их больше 5000, он делит диапазон пополам, пока не добьется полной выгрузки данных.
* **Multiprocessing:** Использование модуля Pool позволяет одновременно скачивать данные из разных ценовых диапазонов. Это ускоряет сбор JSON-файлов, в каждом из которых содержится информация о 100 товарах.
* **Безопасность**: Заголовки (headers) и куки (cookies) вынесены в защищенные переменные окружения (`.env`).
* **Форматированный отчет**: Данные сохраняются в Excel с автоматической подстройкой ширины колонок для удобства чтения.

## Технологический стек

* **Python 3.10+**
* **Requests**: Взаимодействие с API Wildberries.
* **Pandas & Openpyxl**: Обработка данных и генерация Excel-отчетов.
* **Multiprocessing**: Параллелизация процессов.
* **Python-dotenv**: Управление секретами.
* **Json**: Для промежуточного сохранения файлов.

---

## Структура проекта

* `main.py` — основной файл парсера.
* `TelephoneParser/` — папка для промежуточного хранения JSON-ответов.
* `range.txt` — лог рассчитанных ценовых диапазонов.
* `Телефоны.xlsx` — итоговый отчет.
* `.env.range` — шаблон для ваших Cookies и Headers.
